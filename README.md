# Cloudberry

Сайт агентства Cloudberry: мы делаем сайты для баров, пабов и ивент-площадок, где гость видит афишу недели, бронирует стол на схеме зала и подтверждает бронь в Telegram.

Страница собрана как скролл-история в восьми сценах: обзвон отказов, первая бронь от бота, гостья в дверях, лента компаний, полный зал, механика, живое демо брони и форма заявки. Сквозной приём: схема зала в углу экрана, которую сюжет заполняет стол за столом, а в демо она становится кликабельной.

## Структура

```
scrollcraft/builds/cloudberry/
  index.html         разметка страницы
  site.css           стили сайта
  site.js            схема зала, живой фон, демо брони, форма
  scrollcraft.css    движок скролла (не редактируется)
  scrollcraft.js     движок скролла (не редактируется)
  assets/            фото и видео сцен (WebP + MP4, десктоп и телефон)
  BRIEF.md           бриф, партитура сцен, история правок
  gen.sh, cut.py     генерация и обработка ассетов
  lab/*.mjs          скрипты функциональной проверки
screenshot.mjs       скриншоты страницы через Puppeteer
CLAUDE.md            правила работы над проектом
```

## Локальный запуск

```bash
npx --yes serve scrollcraft/builds/cloudberry -l 4500
# затем http://localhost:4500
```

Открывать `index.html` файлом с диска нельзя: видео сцен подгружаются запросом и на `file://` не работают.

## Деплой на Vercel

В репозитории лежит `vercel.json`, который указывает на папку сайта и отключает сборку. Достаточно импортировать репозиторий в Vercel. Если Vercel всё же спросит настройки: Framework Preset `Other`, Root Directory `scrollcraft/builds/cloudberry`, команду сборки оставить пустой.

## Приём заявок (пока не подключён)

Форма в конце страницы проверяет поля, но никуда не отправляет данные: в `site.js` переменная `CONFIG.leadEndpoint` пустая, и в этом случае форма честно пишет, что заявка не отправлена. Ложного «спасибо» посетитель не увидит.

Чтобы включить приём, впишите адрес приёмника:

```js
var CONFIG = { leadEndpoint: 'https://.../api/lead' };
```

Форма отправит `POST` с JSON `{ name, venue, whatsapp }` и покажет успех только при ответе `2xx`. Подходит вебхук (Make, Zapier, Google-таблица, CRM), сервис форм или своя функция на Vercel, которая пересылает заявку боту в Telegram. Токен бота хранится только в переменных окружения Vercel, в коде страницы его быть не должно.

Демо брони в середине страницы всегда остаётся демонстрацией: данные лежат в странице, при перезагрузке сбрасываются, никуда не уходят.

## Проверка вёрстки

```bash
node screenshot.mjs http://localhost:4500 desktop --scroll=0,20,40,60,80,100
node screenshot.mjs http://localhost:4500 mobile --mobile --scroll=0,25,50,75,100
node scrollcraft/builds/cloudberry/lab/mobile-audit.mjs 390 844
```

Скриншоты складываются в папку `temporary screenshots`, она не входит в репозиторий.

## Ассеты

Кадры сделаны через kie.ai (`gen.sh`), герой разложен на слои с прозрачностью через rembg (`cut.py`), видео собраны и закодированы ffmpeg. Мастера генерации лежат локально в `out/` и в репозиторий не входят: в `assets/` уже готовые файлы для сайта.

Для повторной генерации нужен `KIE_AI_API_KEY` в `.env` за пределами репозитория.
